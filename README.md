# 버그 헌터: 깨진 게임 속으로 — 스팀판 (BUG HUNTER, Steam)

팀 겜타즈 2027

> 이 레포는 **스팀 출시용**이에요. saaskr 게임 어워드 제출본은 [ChoeHanMin/BugHunter](https://github.com/ChoeHanMin/BugHunter)에서 따로 관리해요 (그쪽 `dist/index.html`은 건드리지 않음).

## 스팀판에서 바꾼 것 (saaskr 제출본 기준)

- **PC 전용:** 항상 1920×1080 기준 화면을 창 크기에 맞게 통째로 확대·축소 (비율이 다르면 검은 여백). 터치스크린 노트북도 폰 화면으로 바뀌지 않음 (`IS_TOUCH = false`, `VIEW.pc = true`)
- **폰 기능 끔:** "세로로 돌려 주세요" 안내, "가로 화면을 권장해요" 문구, 좁은 화면용 CSS(@media) 9개 삭제
- **문구:** 타이틀 하단 "2026 saaskr 게임 어워드" 삭제, "탭해서 계속" → "클릭해서 계속", 복사 실패 안내 "길게 눌러" → "선택해서 Ctrl+C"
- **그림 화질:** 4MB 제한이 없으니 크게 넣음 (캐릭터 230→460px, 엄폐물 800→2172px, 옆 벽 860→1500px, 버그 96→256px, 총 640→1448px), PNG 팔레트 → webp(q92). 결과 `dist/index.html` 약 3.8MB
- 확인한 화면 크기: 1920×1080, 1366×768, 1280×800(터치), 1280×1024, 2560×1440

## Windows 앱 만들기 (Electron, Wine 필요 없음)

```bash
npm install
node build-desktop.js   # → desktop-out/BugHunter-win32-x64/ + desktop-out/BugHunter_win64_v1.0.0.0.zip
```

- 버전은 `desktop/package.json`의 `version`만 바꾸면 exe 버전 정보와 zip 이름에 같이 들어가요.
- exe 아이콘·버전 정보(회사명 겜타즈 2027)는 resedit(순수 JS)으로 넣어서 rcedit을 따로 돌릴 필요가 없어요.
- 아이콘: `desktop/icon_src.png`(정사각형, 투명 배경)를 넣으면 그 그림을 씀. 없으면 기본 버그 그림(`assets/bug_basic.png`).

| 기능 | 내용 |
|---|---|
| 창 | 처음엔 전체 화면. 창 모드 기본 1280×720, 최소 1024×576. 마지막 전체 화면 여부·창 크기 기억 |
| 전체 화면 전환 | F11 또는 Alt+Enter, 설정 → "전체 화면" 체크 |
| 소리 | 실행하자마자 타이틀 음악이 나옴 (클릭 안내 문구 안 뜸) |

데스크톱 코드: `desktop/main.js`(창·단축키·저장), `desktop/preload.js`(게임에 `window.bhDesktop` 제공). 게임 쪽은 `window.bhDesktop`이 있을 때만 종료 버튼·전체 화면 설정을 보여 줘요.

## 스팀 업로드 (SteamCMD)

`steam/app_build.vdf`의 `APP_ID`, `DEPOT_ID`를 Steamworks 값으로 바꾸고, `BugHunter-win32-x64` 폴더 **안의 파일들**을 `content/`에 넣은 뒤:

```
steamcmd.exe +login <계정> +run_app_build <경로>\steam\app_build.vdf +quit
```

Steamworks → 설치 → 일반 설치에서 실행 옵션: 실행 파일 `BugHunter.exe`, 운영체제 Windows.

## 게임 방식: 쏘고 숨는 엄폐 사격 (2026.11 개편)

- **누르고 있으면** 엄폐물 위로 나와 자동 사격, **떼면** 숨어서 재장전. 폰은 손가락을 끈 만큼 조준점이 움직임(손가락이 조준점을 가리지 않게), PC는 마우스 위치 = 조준점.
- 스테이지마다 **엄폐 지점 3곳 × 웨이브 2개**. 다 처리하면 다음 엄폐물로 이동(이동 중엔 못 쏨). 마지막 지점 = BUG RUSH. 보스는 한 자리.
- **적의 역할**
  - 돌격형(기본·복제·작은 복제): 엄폐물까지 달려와 물기 — **숨어도 맞음**, 쏴서 막아야 함
  - 사격형(throw·투명·404): 멀리 서서 **빨간 예고 원** 뒤 에러 패킷 — **숨으면 엄폐물이 대신 맞음**. 예고 중에 그 버그를 잡으면 공격 취소
  - 무한루프 버그·보스: **관통 미사일** — 숨어도 맞음, 미사일을 쏴서 격추(2발)
- **엄폐물 체력** (하 140 / 중 100 / 상 70). 0이 되면 파괴 → 숨어도 맞음. 다음 엄폐 지점에서 새로 / 핫픽스로 보강.
- **3인 분대**: 도트(연사 9발/초, 탄창 36) · 렉스(산탄 7발, 탄창 8, 스테이지 2 합류) · 핀(저격: 누르고 있으면 충전, 떼거나 다 차면 관통 발사, 스테이지 3 합류). 아래 아이콘 / 1·2·3 / 휠로 교체, 나머지는 자동 사격. 롤백(스페이스)은 분대 스킬, 날아오던 공격도 되감음.
- 버그에 체력이 생김(기본 3, 복제 4, throw 4, 404 4, 무한루프 6 …), 버그 한가운데를 맞히면 2배 피해.
- 캐릭터는 1인칭 손+총으로 보여 주고, 얼굴은 아이콘으로만 표시 (다른 게임의 캐릭터 뒷모습 화면 구성을 따라 하지 않음).

> 아래 "기획서 대비 구현 현황"의 레일 이동·탭 사격·무기 교체 설명은 개편 전 내용이에요.

## 테스트 피드백 반영 (2026.11.25)

- **난이도:** 하·중을 크게 낮춤 (적 공격 간격·예고 시간 증가, 피해·버그 속도 감소, 엄폐물 체력 하 180 / 중 130, 보스 오류 줄 체력 하 ×2.2 / 중 ×3.5 / 상 ×4). 도움 모드 강화: 버그 속도 −20%, 적 공격 느리게, 피해 −20%, 엄폐물 +40%. 하는 1번, 중·상은 2번 연속 크래시하면 켜짐.
- **3인칭 엄폐:** 숨어 있을 땐 카메라가 뒤로 빠지고, 조작 중인 캐릭터가 왼쪽 서버 랙 벽(cover_side.png)에 등을 기댄 전신으로 보임. 빨간 예고·가까운 돌격 버그·미사일이 오면 **움찔** 자세, 맞으면 0.55초 **고통** 자세(+흔들림). 누르면 1인칭 조준으로 전환. 엄폐 지점 사이를 이동할 땐 조준선이 사라지고 화면 가운데에서 달리는 뒷모습(char_*_run.png, run2와 번갈아).
- **보스 체크포인트:** 보스 2·3단계에서 크래시하면 그 단계부터 다시 시작(이미 고친 오류 줄은 고쳐진 채로). 보스방은 난이도와 상관없이 1번만 크래시해도 도움 모드.
- **폰 가로 화면:** 폰(터치, 화면 높이 600px 미만)을 가로로 돌리면 "세로로 돌려 주세요" 안내 + 일시정지. 가로 큰 화면은 PC용.
- **PC 화면:** PC는 1920×1080 기준 화면을 창 크기에 맞게 통째로 확대·축소해요 (비율이 다르면 위아래나 양옆이 검은 여백). 폰·태블릿은 화면 크기 그대로.
- **튜토리얼:** 처음 게임 시작/오늘의 빌드를 누르면 한 번만 "튜토리얼을 먼저 해 볼래요?"를 물어봐요. 끝까지 하면 도전 과제 "훈련 수료".
- **도감:** 타이틀·일시정지 메뉴. 분대 3명·롤백 설명 + 버그 9종(역할, 체력, 특징, 공략, 약점 무기). 만나기 전엔 ???.
- **약점 무기:** 버그 옆 동그라미(연/산/저) = 약점 무기, 그 무기로 쏘면 피해 2배. 산탄은 돌격형을 밀어내고, 저격은 무한루프 껍질을 뚫고 보스 오류 줄에 2배. 상황에 맞는 캐릭터 버튼이 반짝임(추천), 위급할 때 롤백 버튼도 반짝임.
- **롤백:** 버튼에 "3초 슬로우" 표시, 처음 열릴 때 설명 카드.
- **안내 카드(온보딩):** 처음 보는 버그, 분대 합류, 롤백, 첫 공격 예고, 엄폐물 파괴 때 전투를 멈추고 짧게 설명 → 탭해서 계속. 한 번 본 카드는 다시 안 나옴(설정 → 안내 카드 다시 보기).

### 튜토리얼 (난이도 화면 맨 왼쪽)
- 훈련장(크래시 없음, 분대 3명·롤백 모두 열림)에서 순서대로: 화면 구성(안정성·진행률·점수·패치 로그·엄폐물 체력·일시정지) → 조작(누르고 있기·떼기·조준·탄약) → 분대와 무기(도트·렉스·핀, 직접 바꿔 보기, 약점 무기, 롤백) → 버그 7종을 한 마리씩
- 설명하는 부분만 컬러, 나머지는 흑백 (backdrop-filter). 새 버그·첫 공격 예고·첫 관통 미사일이 나오면 **슬로우 + 그 대상만 컬러**로 비추고 설명
- 설명 카드는 탭(또는 스페이스·엔터)으로 넘기고, 조작 단계는 직접 해야 넘어감. 끝나면 난이도 화면으로

### 2차 조정 (팀 피드백: 초반이 너무 쉬움)
- 동료 자동 사격은 플레이어가 나와서 쏠 때만 (숨어 있을 때 레이저가 나가던 문제 수정)
- 버그 수: 스테이지 18 / 22 / 26 / 28 (전: 14 / 18 / 22 / 24), 중 난이도 ×1.15, 한 화면 최대 9
- 속도: 하 ×0.82 · 중 ×1.02 · 상 ×1.25, 스테이지마다 +8%, 엄폐 지점마다 +6%, 웨이브마다 +2%
- 중 난이도 적 공격 간격 ×1.25 → ×1.08, 스테이지 1에 throw 버그 비중 증가, 사격형은 자리 잡자마자 0.25~0.75초 안에 공격
- 보스는 1차 조정(라운드 5 피드백) 그대로

### 밸런스는 어떻게 맞추나요
헤드리스 브라우저에서 봇 두 종류로 실제 게임을 끝까지 돌려 봐요.
- **사람처럼 서툰 봇:** 공격 예고를 0.5초 늦게 알아채고 15%는 놓침, 조준이 느리고 오차가 큼
- **정확한 봇:** 반응·조준이 빠름

목표: 하 = 서툰 봇이 크래시 없이 여유 있게 / 중 = 서툰 봇이 가끔 맞지만 깸 / 상 = 서툰 봇은 못 깨고 정확한 봇은 겨우 깸.
봇은 화면을 "보는" 게 아니라 게임 속 숫자를 읽기 때문에 사람보다 유리해요. 그래서 봇 결과보다 한 단계 쉽게 맞추고, 사람 테스트 결과로 다시 조정해요.

## 기획서 대비 구현 현황

- 레일 이동(자동 전진), 탭/클릭 조준, 조준 보정(모바일 48px / PC 16px), 누르고 있으면 초당 4발
- 무기 3종: 디버거 / 리팩터(7발 부채꼴, 충전 3초, 스테이지 2 해금) / 롤백(3초 30% 속도, 스테이지당 2회, 고장 1개 즉시 복구, 스테이지 3 해금)
- 버그 5종: 기본 · 복제(1회 분열) · 투명(1.5초마다 0.5초 보임) · 404(조준선 1초 겹치면 순간이동, 게이지 표시) · 무한루프(빛나는 지점에서만 맞음)
- 안정성 100% · 접촉 시 감소 + 화면 고장 5종(최대 2개 겹침) · 5연속 패치 시 가장 오래된 고장 복구 · 클리어 시 +30%
- 크래시 → 해당 스테이지만 재도전 · 2연속 크래시 시 도움 모드(버그 속도 −15%, 결과 "출시 연기")
- 스테이지 5개 + 보스 3단계 (2단계: 버그를 뱉음 / 3단계: 두 마리로 복제, 진짜만 오류 줄이 빛남) → "BUILD SUCCESS" 정상화 연출
- 고친 버그 근처부터 색이 차오름, 클리어 시 고치기 전/후 와이프 연출
- 등급 4종, 패치 노트 카드(20여 문구 조합) + 복사(클립보드 → 실패 시 텍스트 선택/길게 눌러 복사)
- 오늘의 빌드(날짜 시드: 버그 순서·고장 가중치·보스 3단계 패턴), 기록, 도전 과제 6개
- 설정: 소리, 효과음/음악 크기, 깜빡임 효과 줄이기, 화질(자동/높음/낮음) · 프레임이 떨어지면 해상도 자동 하향
- iframe 대응: 포인터 잠금 미사용, 저장 막혀도 진행, 확대·스크롤·길게 누르기 메뉴 차단

## 재미 패치 (기획서에 추가한 것)

- **손맛:** 화면 오른쪽 아래 패치 건(조준 방향으로 회전, 반동·총구 불꽃), 맞힐 때 화면 흔들림·짧은 멈춤(히트스톱), 연속으로 고칠수록 효과음 음정 상승, 연속 ×2.0이면 배율 글자 노란색
- **PERFECT:** 버그 한가운데를 디버거로 맞히면 점수 ×1.5 + 반짝 효과음
- **긴장감:** 버그가 가까이 오면 빨간 테두리 + "!" + 경고음, 화면 밖 버그는 가장자리에 빨간 화살표
- **BUG RUSH:** 스테이지 70% 지점부터 남은 버그 30%가 몰려옴 (배너 + 음악 빨라짐)
- **핫픽스 아이템:** 스테이지마다 1~2개(보스 2·3단계 시작 때도) 둥실 떠다님. 쏘면 안정성 +20, 화면 고장 모두 복구(가득이면 +500점). 6초 뒤 사라짐
- **보스 1단계**도 4.5초마다 버그를 뱉음
- **BGM:** 타이틀은 느리고 웅장한 테마(팀파니·현악 패드·합창·금관 멜로디), 스테이지는 단조 행진(고칠수록 베이스→현악·금관→영웅 테마→합창·아르페지오), 보스는 빠르고 긴박하게. 모두 Web Audio로 직접 합성
- **패치 로그:** 왼쪽 코드 창. 고치면 `-`/`+` 패치 코드 + `✔ Run Successfully`, 버그에 맞으면 에러 + `✖ Run Error(0x######)`(랜덤 숫자)

## 난이도 (하 · 중 · 상)

게임 시작 / 오늘의 빌드 → 난이도 선택. 결과 화면과 패치 노트에 난이도가 표시돼요. **상은 중(또는 상)을 한 번 끝까지 깨야 열려요** (브라우저에 기록, 저장이 막힌 환경에서는 그 접속 동안만).

| | 하 | 중 | 상 |
|---|---|---|---|
| 버그 속도 · 피해 | ×0.8 · ×0.7 | 기획서 그대로 | ×1.15 · ×1.15 |
| 버그 수 · 한 화면 최대 | ×0.85 · 6 | ×1 · 8 | ×1.25(물리 구역은 ×1) · 10, **3초마다 끝없이 추가** |
| 복제 버그 | 제자리 분열 | 제자리 분열 | **화면 반대편·높은 곳으로 튐** |
| 돌진 | — | — | 28%가 0.5초 예고(멈춰서 부르르, !!) 뒤 1.9배 돌진 |
| 패치 건 과열 | — | — | 연사하면 열이 쌓여 가득 차면 **연기 + 2초 못 쏨**, 18~30초마다 **갑자기 과열** |
| 핫픽스 | +1개 | 그대로 | 1개, 40%는 **트로이 목마**(쏘면 버그 3마리, 붉게 깜빡임) |
| 롤백 · 고장 복구 콤보 | 3회 · 5연속 | 2회 · 5연속 | 1회 · 8연속 |
| 화면 고장 | 짧게, 2개 | 그대로, 2개 | 길게, 최대 3개 |
| 보스 | 느림, 체력 −1 | 그대로 | 1.3배 빠름, 체력 +2, 버그 더 자주 |

봇 테스트 기준: 상은 반응이 느린 봇은 못 깨고, 정확한 봇도 안정성 25~40%까지 떨어지며 겨우 깸.
도전 과제 추가: "난이도 상 클리어", "난이도 상에서 정식 출시".

## 기획서와 다르게 정한 것 (확인 필요)

- **보스 오류 줄은 여러 발**(1단계 3발, 2단계 4발, 3단계 5발)을 맞혀야 고쳐짐. 한 발이면 보스가 10초 안에 끝나서 조정함.
- 롤백 해금은 스테이지 표(스테이지 3)를 따름 (무기 설명의 "스테이지 2부터"와 다름).
- "게임 시작"은 고정 시드, "오늘의 빌드"는 날짜 시드.
- 복제 버그 본체는 점수 0점(분열만), 작은 복제 50점. 보스 오류 줄 400점(기획서에 없어 임의로 정함).
